# 指紋棉花棒創作

用手指蓋指紋、用棉花棒點點點，再用簽字筆畫幾筆，一步一步完成一張作品。給社區長輩、學生、老師上課用的免費教案。

- 三種紙：方形 1:1、圓形、4:5 直式，各 12 課（入門、進階、挑戰各 4 課），共 36 課
- 分三級：入門（一種工具、幾個步驟）、進階（指紋加棉花棒、兩色輪流）、挑戰（一圈一圈、多色、很多細節）
- 一步一步的動畫：手指或棉花棒沾顏料、移到位置、壓下留下印痕，簽字筆一筆一筆畫出來，每一步都有口語說明
- 猜猜看：規律接龍，給前面幾個指紋或點點，猜下一個的顏色、工具、大小、方向
- 老師設計：在紙上點一下蓋指紋（拖曳決定方向）、拖曳一路點點、畫線、擦掉；排列小幫手可以一次排一圈、一排、格子、放射；步驟說明自動產生也能改寫
- 下載：步驟動畫影片（16:9／9:16／1:1）、A4 學習單 PDF（作品與材料、步驟圖、照著蓋的底稿）、完成圖 PNG、教案檔 JSON
- 手機可用：播放鍵固定在底部、點畫面播放暫停、左右滑換步驟、頁內投影模式

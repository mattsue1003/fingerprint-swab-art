# 蓋印章圖樣生成器

用海綿、橡皮擦、瓶蓋、手指當印章，一步一步排出有規律的花紋。給社區長輩、學生、老師上課用的免費教案。

- 18 課範例，分三級：入門（單色平移）、進階（兩色交錯、鏡射）、挑戰（旋轉、放射、多色規律）
- 一步一步的蓋章動畫：印章沾顏料、移到位置、壓下、留下印痕，每一步都有口語說明
- 猜猜看：給前面幾個印章，猜下一個是什麼形狀、什麼顏色、什麼方向
- 老師設計：選印章、排列規則（平移／交錯／放射）、形狀、2～4 色配色、旋轉、鏡射、大小漸層，步驟說明自動產生也能改寫
- 下載：步驟動畫影片（16:9／9:16／1:1）、A4 學習單 PDF（教案、照著蓋、接下去蓋）、完成圖 PNG、教案檔 JSON
- 手機可用：播放鍵固定在底部、點畫面播放暫停、左右滑換步驟、頁內投影模式

網站：https://mattsue1003.github.io/stamp-pattern/

更新方式：修改 `../蓋印章圖樣生成器.html` 後執行 `./build.sh`，再 commit、push。
